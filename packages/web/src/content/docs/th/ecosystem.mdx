ชุดโครงการชุมชนที่สร้างขึ้นบน Coder

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Coder ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-coder](https://github.com/awesome-coder/awesome-coder) และ [coder.cafe](https://coder.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
