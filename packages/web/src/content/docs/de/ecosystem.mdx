Eine Sammlung von Community-Projekten, die auf Coder basieren.

:::note
Möchten Sie Ihr Coder-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-coder](https://github.com/awesome-coder/awesome-coder) und [coder.cafe](https://coder.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
