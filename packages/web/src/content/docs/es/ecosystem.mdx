Una colección de proyectos comunitarios construidos en Coder.

:::note
¿Quieres agregar tu proyecto relacionado con Coder a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-coder](https://github.com/awesome-coder/awesome-coder) y [coder.cafe](https://coder.cafe), una comunidad que agrega el ecosistema y la comunidad.
