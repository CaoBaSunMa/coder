---
title: "Commands"
description: "Reference for the coder command line."
---

Every command accepts `--help` for its full flag list, for example `coder run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ coder run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Coder review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @xcoder/cli
      - run: coder run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ coder run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ coder run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ coder run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ coder run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ coder run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ coder run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ coder mini
```

Continue the last session.

```bash
$ coder mini --continue
```

Start with a model and an initial prompt.

```bash
$ coder mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

View all subcommands and flags.

```bash
$ coder mini --help
```

## session

Manages sessions.

```bash
$ coder session list
```

Limit the list and print JSON.

```bash
$ coder session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ coder session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ coder session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ coder session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ coder session import session.json
```

Import into a specific directory.

```bash
$ coder session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ coder session --help
```

## auth

Manages AI providers and credentials.

```bash
$ coder auth list
```

List them as JSON.

```bash
$ coder auth list --format json
```

Log in to a provider.

```bash
$ coder auth login anthropic
```

Log in with a specific authentication method.

```bash
$ coder auth login anthropic --method key
```

Log out of a saved account.

```bash
$ coder auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ coder auth switch anthropic work
```

View all subcommands and flags.

```bash
$ coder auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ coder mcp list
```

Add a remote server.

```bash
$ coder mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ coder mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ coder mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ coder mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ coder mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ coder mcp logout sentry
```

View all subcommands and flags.

```bash
$ coder mcp --help
```

Manages plugins.

```bash

```

Include built-in server plugins.

```bash
$ coder plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ coder plugin add @example/coder-tui
```

Check package plugins for updates.

```bash
$ coder plugin check
```

```bash
$ coder plugin update
```

Remove a plugin from global configuration.

```bash
$ coder plugin remove @example/coder-tui
```

View all subcommands and flags.

```bash
$ coder plugin --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ coder serve
```

Bind to all interfaces on a fixed port.

```bash
$ coder serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ coder serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ coder serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ coder pair
```

Use an external URL in the links.

```bash
$ coder pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ coder pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ coder pair --remote --yes
```

View all subcommands and flags.

```bash
$ coder pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ coder service start
```

Restart it.

```bash
$ coder service restart
```

Show its status.

```bash
$ coder service status
```

Stop it.

```bash
$ coder service stop
```

Read a setting.

```bash
$ coder service get hostname
```

Set a setting.

```bash
$ coder service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ coder service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ coder service set env CODER_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ coder service unset hostname
```

View all subcommands and flags.

```bash
$ coder service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ coder reload
```

## api

Makes a request to the running server.

```bash
$ coder api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ coder api session.list --param limit=10
```

Send a JSON body.

```bash
$ coder api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ coder api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ coder api --help
```

## upgrade

Upgrades Coder to the latest or a specific version. Alias: `update`.

```bash
$ coder upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ coder upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ coder upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls Coder. Session data, configuration, and
state are not removed.

```bash
$ coder uninstall
```

Preview what would be removed.

```bash
$ coder uninstall --dry-run
```

View all subcommands and flags.

```bash
$ coder uninstall --help
```
